# Discipline 31

An installable iPhone home-screen web app with an 8-item daily checklist, 31-day progress grid, streak count, rotating Bible verses, and local progress storage.

## Install on iPhone
1. Upload all files in this folder to a static HTTPS host such as GitHub Pages.
2. Open the published HTTPS URL in Safari on your iPhone.
3. Tap Share → Add to Home Screen → Add.

## GitHub Pages
Create a repository named `discipline31`, upload these files to its root, then go to Settings → Pages and deploy from the `main` branch, root folder. Open the published URL in Safari.

Progress is stored locally in that browser on that device; it does not sync across devices. HTTPS is required for offline caching/service workers.
